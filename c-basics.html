Introduction to C

C is a general-purpose, procedural programming language developed in the early 1970s. It is one of the most widely used programming languages of all time and forms the foundation for many modern languages like C++, Java, and Python.

C gives the programmer direct control over memory and hardware, making it extremely powerful and efficient. It is often called the "mother of all programming languages."

💡 Why Learn C First? Learning C builds a strong foundation — once you know C, picking up any other language becomes much easier because C teaches you how computers actually work.
02
History of C

C was developed at Bell Laboratories by Dennis Ritchie between 1969 and 1973. It evolved from an earlier language called B, which itself came from BCPL.

YearEvent
1967BCPL language developed by Martin Richards
1969B language created by Ken Thompson at Bell Labs
1972C language created by Dennis Ritchie at Bell Labs
1978"The C Programming Language" book published by Kernighan & Ritchie (K&R C)
1989ANSI standardized C → called C89 or ANSI C
1990ISO adopted the standard → called C90
1999C99 released with new features
2011C11 — latest major standard
👨‍💻 Dennis Ritchie Often called the father of C. He also co-created the Unix operating system. C was originally designed to write Unix — that's why it's so close to the hardware.

#include <stdio.h>

int main() {

07
Variables & Constants

A variable is a named memory location that stores a value which can change during program execution.

Syntax: data_type variable_name = value;

variables.c 
int age = 20;           // declaration + initialization
float salary;           // declaration only
salary = 25000.50;      // assignment later

// Multiple variables
int a = 5, b = 10, c = 15;

Rules for naming variables:

⚠️ Naming Rules Must start with a letter or underscore _ · Can contain letters, digits, underscores · No spaces or special characters · Cannot use C keywords (like int, if, for) · Case sensitive (age ≠ Age ≠ AGE)

A constant is a value that cannot change during program execution.

constants.c 
// Method 1: using #define (macro)
#define PI 3.14159
#define MAX 100

// Method 2: using const keyword
const int DAYS = 7;
const float RATE = 8.5;

09
Input & Output

C uses printf() for output and scanf() for input. Both are defined in <stdio.h>.

Format Specifiers:

SpecifierData Type
%dint
%ffloat
%lfdouble
%cchar
%sstring
%ldlong int
input_output.c 
#include <stdio.h>

int main() {
    int age;
    float marks;

    printf("Enter your age: ");
    scanf("%d", &age);         // & is address-of operator

    printf("Enter your marks: ");
    scanf("%f", &marks);

    printf("Age = %d, Marks = %.2f\n", age, marks);

    return 0;
}
⚠️ Important! Always use & before variable name in scanf() — it gives the memory address where the input should be stored.

if / else Statement

The if-else statement is used for decision making — it runs different code based on whether a condition is true or false.

Types of if-else:

1. Simple if

simple_if.c 
if (age >= 18) {
    printf("You can vote!\n");
}

2. if-else

if_else.c 
if (marks >= 40) {
    printf("Pass\n");
} else {
    printf("Fail\n");
}

3. if-else if-else (ladder)

ladder.c 
if (marks >= 90) {
    printf("Grade A\n");
} else if (marks >= 75) {
    printf("Grade B\n");
} else if (marks >= 60) {
    printf("Grade C\n");
} else {
    printf("Grade D\n");
}

4. Nested if-else

nested_if.c 
if (age >= 18) {
    if (hasVoterID == 1) {
        printf("Can vote!\n");
    } else {
        printf("Get voter ID first\n");
    }
} else {
    printf("Too young to vote\n");
}
11
switch Statement

The switch statement is used when you want to compare one variable against multiple fixed values. It is cleaner than writing many if-else if statements.

switch.c 
#include <stdio.h>

int main() {
    int day;
    printf("Enter day number (1-7): ");
    scanf("%d", &day);

    switch (day) {
        case 1:
            printf("Monday\n");
            break;
        case 2:
            printf("Tuesday\n");
            break;
        case 3:
            printf("Wednesday\n");
            break;
        case 7:
            printf("Sunday\n");
            break;
        default:
            printf("Invalid day\n");
    }
    return 0;
}
📌 Important Rules Always use break at the end of each case — without it, execution "falls through" to the next case. The default case runs when no case matches (like the else in if-else).

12
Loops

Loops are used to repeat a block of code multiple times. C has three types of loops.

1. for loop — used when you know how many times to repeat

for_loop.c 
// Syntax: for(initialization; condition; update)

for (int i = 1; i <= 5; i++) {
    printf("%d\n", i);
}
// Output: 1 2 3 4 5

// Print multiplication table of 5
for (int i = 1; i <= 10; i++) {
    printf("5 x %d = %d\n", i, 5 * i);
}

2. while loop — used when you don't know how many times to repeat

while_loop.c 
// Syntax: while(condition) { ... }

int i = 1;
while (i <= 5) {
    printf("%d\n", i);
    i++;
}
// Output: 1 2 3 4 5

// Keep asking until user enters 0
int num;
while (num != 0) {
    printf("Enter number (0 to stop): ");
    scanf("%d", &num);
}

3. do-while loop — runs at least ONCE, then checks the condition

dowhile_loop.c 
// Syntax: do { ... } while(condition);

int i = 1;
do {
    printf("%d\n", i);
    i++;
} while (i <= 5);
// Output: 1 2 3 4 5
LoopChecks conditionMin runsBest for
forBefore each iteration0 timesKnown number of repetitions
whileBefore each iteration0 timesUnknown repetitions, condition first
do-whileAfter each iteration1 time alwaysMenu-driven programs

Loop Control Statements:

loop_control.c 
// break — exits the loop immediately
for (int i = 1; i <= 10; i++) {
    if (i == 5) break;   // stops at 5
    printf("%d ", i);    // prints 1 2 3 4
}

// continue — skips current iteration
for (int i = 1; i <= 5; i++) {
    if (i == 3) continue;  // skips 3
    printf("%d ", i);       // prints 1 2 4 5
}
13
Functions

A function is a block of code that performs a specific task. Functions help you avoid repeating code and make programs easier to understand.

Every C program has at least one function — main().

function_syntax.c 
// Syntax:
return_type function_name(parameters) {
    // body
    return value;
}

Example — function with no return value:

functions.c 
#include <stdio.h>

// Function declaration (prototype)
void greet();
int  add(int a, int b);

int main() {
    greet();                    // call greet function
    int sum = add(5, 3);        // call add function
    printf("Sum = %d\n", sum);
    return 0;
}

// Function definitions
void greet() {
    printf("Hello from greet function!\n");
}

int add(int a, int b) {
    return a + b;
}
