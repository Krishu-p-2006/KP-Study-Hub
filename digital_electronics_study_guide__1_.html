Logic Gates & Circuit Design

⚡ Logic Gates Overview
A logic gate is a basic building block of digital circuits that performs a Boolean operation on one or more binary inputs and produces a single binary output.

The Six Fundamental Gates:

OR Gate
🔵
Y = A + B
Output is 1 if any input is 1
AND Gate
🟢
Y = A · B
Output is 1 only if all inputs are 1
NOR Gate
🔴
Y = (A + B)′
Inverted OR. Universal gate.
NAND Gate
🟠
Y = (A · B)′
Inverted AND. Universal gate.
XOR Gate
🟣
Y = A ⊕ B
Output 1 when inputs differ
XNOR Gate
⚪
Y = (A ⊕ B)′
Output 1 when inputs are equal

📐 De Morgan's Laws

De Morgan's theorems are fundamental for simplifying and transforming Boolean expressions.

First Theorem
(A · B)′ = A′ + B′
The complement of a product = sum of complements.
NAND → bubble the inputs and change AND to OR.
Second Theorem
(A + B)′ = A′ · B′
The complement of a sum = product of complements.
NOR → bubble the inputs and change OR to AND.
Quick Rule: To apply De Morgan's — Break the bar, change the operator (AND ↔ OR, + ↔ ·, complement each variable).
Dual PrincipleEvery Boolean identity has a dual: swap AND↔OR and 0↔1 throughout.
Multi-variable(A·B·C)′ = A′+B′+C′ — De Morgan's extends to n-variable expressions.
VerificationAlways verify with a truth table after applying De Morgan's transformation.

🗺️ Circuit Design: SOP, POS & K-Map
Sum of Products (SOP) Boolean function expressed as OR of AND terms (minterms).
F = A'B + AB' + AB
Each AND term = one row where output = 1.
Product of Sums (POS) Boolean function expressed as AND of OR terms (maxterms).
F = (A+B)(A'+B')
Each OR term = one row where output = 0.

Karnaugh Map (K-Map) — Simplification Technique:

A K-Map groups adjacent 1s (for SOP) or 0s (for POS) in powers of 2 (1, 2, 4, 8…) to eliminate variables and produce the minimal expression.

Example K-Map for F(A,B,C,D):

Group Blue: A'C' → 2-cell pair Group Green: A'B eliminated Group Yellow: BC simplified
Rules for GroupingGroups must be rectangles of size 1, 2, 4, 8 cells. Groups can wrap around edges. Larger groups = more variables eliminated.
Prime ImplicantA group that cannot be included in a larger group. Essential prime implicants must appear in the final expression.
Don't Cares (X)Cells with undefined output (marked X) can be treated as 0 or 1 — use them to form larger groups and simplify further.
Unit II

Combinational Building Blocks

🔀 Multiplexer & Demultiplexer
Multiplexer (MUX) "Many to One" — selects one of N input lines and routes it to a single output using select lines.

A 2ⁿ-to-1 MUX needs n select lines.
Example: 4×1 MUX has 4 inputs, 2 select lines, 1 output.

Expression: Y = S'·I₀ + S·I₁ (for 2:1 MUX)
Demultiplexer (DEMUX) "One to Many" — routes a single input to one of N output lines using select lines.

A 1-to-2ⁿ DEMUX needs n select lines.
Example: 1×4 DEMUX has 1 input, 2 select lines, 4 outputs.

Note: Decoder with enable = DEMUX.
MUX as Universal Logic: Any Boolean function of n variables can be implemented using a 2ⁿ⁻¹-to-1 MUX. MUX is also used in data routing, time-division multiplexing, and function generators.

🔢 Encoder & Decoder
Decoder Converts an n-bit binary code to one of 2ⁿ unique outputs (active high or low).
A 3-to-8 decoder: 3 inputs → 8 output lines, only one HIGH at a time.

Enable pin: When EN=0, all outputs = 0. Used to expand decoders.
Uses: Memory address decoding, demultiplexing, BCD-to-7 segment.
Encoder Performs the reverse: 2ⁿ input lines → n-bit binary output.
An 8-to-3 encoder: 8 inputs → 3-bit binary code.

Priority Encoder: When multiple inputs are active, it encodes the highest-priority (usually highest-numbered) input. Resolves ambiguity. Has a Valid Output (V) flag.

BCD to 7-Segment Decoder: A practical decoder that converts a 4-bit BCD value (0–9) to the 7 segment signals (a,b,c,d,e,f,g) needed to drive a 7-segment LED display.

➕ Adder & Subtractor
Half Adder Adds two 1-bit numbers. Outputs: Sum (S) and Carry (C).
S = A ⊕ B    C = A · B
No carry-in input.
Full Adder Adds two 1-bit numbers + carry-in (Cᵢₙ).
S = A ⊕ B ⊕ Cᵢₙ
Cₒᵤₜ = A·B + B·Cᵢₙ + A·Cᵢₙ
Ripple Carry Adder Chain of full adders. Carry "ripples" from LSB to MSB. Simple but slow for large n due to propagation delay.
Carry Look-Ahead Adder Computes all carries in parallel using Generate (G=A·B) and Propagate (P=A⊕B) signals. Faster — O(log n) delay.

Binary Subtraction using 2's Complement:

A – B = A + (2's complement of B) = A + (B' + 1). The same adder circuit with XOR gates and a carry-in of 1 can perform both addition and subtraction. This is implemented in the Adder-Subtractor circuit using a Mode control (M).
M=0 → Addition (A + B)
|
M=1 → Subtraction (A – B)

Half Subtractor: Computes Difference (D = A⊕B) and Borrow (Bₒᵤₜ = A'·B). Full Subtractor adds a borrow-in input.

Unit III

Memory Devices

💾 ROM, PROM & EPROM
Read-Only Memory (ROM) is non-volatile memory whose contents are permanently or semi-permanently stored and can only be read during normal operation, not written.
ROM (Mask ROM) Programmed during fabrication. Contents fixed by the chip manufacturer's mask. Cannot be altered after manufacture. Used for firmware, boot code.
PROM Programmable ROM — blank from factory. User programs it once using a PROM programmer (blows fuses). Cannot be reprogrammed after.
EPROM Erasable PROM — can be reprogrammed. Erased by exposing the quartz window to UV light for 15–20 min. Reprogrammed electrically. Identified by quartz window on chip.
EEPROM Electrically Erasable PROM — erased and reprogrammed electrically, byte-by-byte, without removal from circuit. Slower write than RAM.
Flash Memory Modern evolution of EEPROM. Erased in blocks (not bytes). Fast, dense, used in SSDs, USB drives, memory cards. NAND Flash for storage, NOR Flash for execute-in-place.
ROM as Combinational Circuit A 2ⁿ × m ROM = n-to-2ⁿ decoder + m OR gates. Can implement any Boolean function of n variables with m outputs.

🧠 RAM Types
Random Access Memory (RAM) allows data to be read and written at any address in roughly equal time. It is volatile — contents are lost when power is removed.
Static RAM (SRAM) Uses flip-flop (6-transistor cell) to store each bit. Retains data as long as power is on — no refresh needed.
  • Faster access (~1–10 ns)
  • More expensive, lower density
  • Used in CPU cache (L1, L2, L3)
  • Low power in standby
Dynamic RAM (DRAM) Uses 1-transistor + 1-capacitor cell. Capacitor leaks charge → must be refreshed every ~64 ms.
  • Slower access (~50–100 ns)
  • Cheap, high density
  • Used as main memory (DDR4/DDR5)
  • Requires refresh circuitry
💿 Hard Disk, Floppy Disk & CD-ROM
Hard Disk Drive (HDD) Magnetic storage on spinning platters coated with ferromagnetic material. Read/write heads on actuator arms hover nanometers above the surface. Organized as: Platters → Tracks → Cylinders → Sectors (512B or 4KB each). Access time = Seek time + Rotational latency + Transfer time.
Floppy Disk Removable, flexible magnetic disk. 3.5" HD floppy = 1.44 MB. Two-sided, 80 tracks per side, 18 sectors per track. Now obsolete; replaced by USB and optical media. Uses similar magnetic recording to HDD but slower.
CD-ROM Optical storage: laser reads pits (0) and lands (1) pressed into a polycarbonate disc. 650–700 MB capacity. Constant Linear Velocity (CLV) — disc spins faster when reading inner tracks. 1× = 150 KB/s read speed.

Sequential Building Blocks

🔄 Flip-Flops
A flip-flop is a bistable multivibrator — a sequential circuit that stores 1 bit of information. Unlike combinational circuits, its output depends on both current inputs and the previous state.
SR Flip-Flop
Set (S) = 1 → Q becomes 1
Reset (R) = 1 → Q becomes 0
S=R=0 → Hold (no change)
S=R=1 → Forbidden / Invalid state
Built from NAND or NOR gates
D Flip-Flop (Data/Delay)
D input directly determines next state
On clock edge: Q(next) = D
Eliminates forbidden state of SR FF
Used in registers, data storage
Most widely used flip-flop
JK Flip-Flop
J=K=0 → Hold (no change)
J=1, K=0 → Set (Q=1)
J=0, K=1 → Reset (Q=0)
J=K=1 → Toggle (Q flips)
Universal FF — no forbidden state
T Flip-Flop (Toggle)
T=0 → Hold (no change)
T=1 → Toggle (Q flips)
Derived from JK with J=K=T
Used in binary counters
Output frequency = clk/2
Master-Slave JK FF
Two FFs cascaded: Master + Slave
Master captures input on CLK=1
Slave transfers to output on CLK=0
Eliminates race condition (1s catching)
Edge-triggered behavior achieved
Edge Triggering: Modern flip-flops are edge-triggered — they respond only on the rising edge (↑) or falling edge (↓) of the clock, preventing timing hazards during the stable clock level.
📦 Registers & Shift Registers

A register is a group of flip-flops used to store multiple bits simultaneously. An n-bit register = n flip-flops.

SISO (Serial-In Serial-Out) Data enters and exits one bit at a time. n clock pulses needed to shift n bits. Used as delay lines and data buffers.
SIPO (Serial-In Parallel-Out) Data enters serially; all bits available simultaneously at output. Converts serial data to parallel (e.g., UART receiver).
PISO (Parallel-In Serial-Out) All bits loaded simultaneously; shifted out one by one. Converts parallel data to serial (e.g., UART transmitter).
PIPO (Parallel-In Parallel-Out) All bits loaded and read simultaneously. Fastest mode. Used as temporary storage registers in CPUs (accumulators, data registers).
Bidirectional Shift Register Can shift data left or right. Direction controlled by a mode select pin. Used in arithmetic operations (shift left = ×2, shift right = ÷2).
Universal Shift Register Supports all four modes: SISO, SIPO, PISO, PIPO, left shift, right shift. Most flexible. Example: 74HC194.
🔢 Counters — Synchronous & Asynchronous
A counter is a sequential circuit that cycles through a predetermined sequence of states in response to clock pulses. It counts events, measures time, and generates addresses.
Asynchronous (Ripple) Counter Only the first FF is clocked by the external clock. Each subsequent FF is clocked by the output of the previous one. The carry "ripples" through.
✅ Simple circuit, fewer connections
❌ Slower — propagation delay accumulates (td × n)
❌ Glitches in intermediate states
Example: 4-bit ripple counter with 4 T FFs.
Synchronous Counter All flip-flops share the same clock — triggered simultaneously. Carry logic computed in parallel using AND gates.
✅ Faster — no ripple delay
✅ No glitches in intermediate states
❌ More complex logic circuitry
Used in high-speed digital systems, CPUs, and signal processing.

Mod-N CounterCounts from 0 to N–1, then resets. A Mod-6 counter uses 3 FFs and resets on state 6. Built by adding a combinational reset logic.
Ring CounterSingle 1 circulates through n FFs. n-bit ring = n states. Simple, no decoding needed. Useful for timing and sequencing.
Johnson CounterComplement of output fed back to input. 2n states from n FFs. More states than ring counter. Used in decade counters.
Up/Down CounterCounts upward or downward based on a direction control input. Used in bidirectional control applications.
Unit V

Memory Organization

🔬 Basic Cell of Static & Dynamic RAM
SRAM Cell (6-Transistor) Composed of 2 cross-coupled CMOS inverters (4 transistors) + 2 access transistors.

Operation:
• Write: Assert word line → bit lines drive the cross-coupled pair to desired state
• Read: Assert word line → sense amplifier detects small differential voltage on bit lines
• Hold: Word line de-asserted → inverter pair holds state indefinitely (power on)

No refresh needed. State held by regenerative feedback.
DRAM Cell (1T-1C) Composed of 1 access transistor + 1 capacitor.

Operation:
• Write: Assert row select → charge/discharge capacitor via bit line
• Read: Assert row select → small charge on capacitor shared with bit line; sense amplifier detects and restores (destructive read)
• Refresh: Capacitor leaks ~every 64 ms → memory controller must read and rewrite each row periodically

Destructive read — data must be rewritten after reading.

🏗️ Building Large Memories Using Chips

A single memory chip may not provide sufficient address space or word width. We combine chips to build larger memories.

Word Length Expansion To increase word width: connect chips in parallel (same address lines, different data lines). Example: Two 1K×4 chips → 1K×8 memory. Address lines shared; data lines doubled.
Address Space Expansion To increase addressable locations: connect chips in series with a decoder selecting the active chip. Example: Two 1K×8 chips → 2K×8 memory. A higher address bit selects the chip via CS (chip select).
Chip Select (CS) Each chip has a CS̄ (active low) pin. Decoder output drives CS̄. Only the selected chip drives the data bus; others are in high-impedance (tri-state). Prevents bus contention.
Combined Expansion Real systems expand both word length and address space simultaneously. Memory map partitions address space into banks, each served by a chip group.
Example: Build 8K×16 from 2K×8 chips. Need 4 chips for word expansion (2×2K×8 → 2K×16) and 4 banks for address expansion (4×2K = 8K). Total: 4 × 4 = 16 chips. A 2-to-4 decoder selects the active bank using address bits A11–A10.
⚡ Associative Memory & Cache Memory Organization
Associative Memory (Content-Addressable Memory — CAM): Unlike RAM (addressed by location), CAM is addressed by content. A search key is compared simultaneously with all stored entries; matching locations return their addresses or data. Used in TLBs, routers, and cache tag arrays.
Cache Memory A small, fast SRAM buffer between the CPU and slower main memory (DRAM). Stores recently and frequently used data. Hit ratio h = (cache accesses) / (total accesses). Average access time = h·tC + (1–h)·tM.
Locality of Reference Temporal: Recently accessed data likely reused soon.
Spatial: Data near recently accessed locations likely used soon.
Cache exploits both types of locality.

Cache Mapping Techniques:

Direct Mapping Each main memory block maps to exactly one cache line. Address = Tag | Line Index | Block Offset. Simple, fast, but suffers from conflict misses.
Fully Associative Any block can go into any cache line. Uses CAM for tag comparison. Highest flexibility, lowest miss rate — but expensive comparator hardware.
Set-Associative (n-way) Cache divided into sets; each block maps to one set but can occupy any of n lines within that set. Balance between direct and fully associative. Most common (e.g., 8-way L3 cache).
Replacement Policies When a cache set is full: LRU (evict least recently used), FIFO (evict oldest), Random (evict random line — simple, surprisingly effective).
Write Policies Write-through: Write to both cache and main memory simultaneously. Consistent but slower.
Write-back: Write only to cache; update main memory when line is evicted (dirty bit used).
Cache Levels Modern CPUs: L1 (4–64 KB, ~1 ns, per-core), L2 (256 KB–4 MB, ~5 ns, per-core), L3 (4–64 MB, ~20 ns, shared). Larger = slower = cheaper per bit.

🌐 Virtual Memory Organization
Virtual Memory creates the illusion of a large, contiguous address space for each process, even when physical RAM is smaller. The OS and MMU (Memory Management Unit) manage the translation between virtual addresses (used by programs) and physical addresses (actual RAM locations).
Paging Virtual and physical memory divided into fixed-size pages (typically 4 KB). OS maintains a Page Table per process. Virtual address = Page Number + Page Offset. Page Table maps VPN → PFN (Physical Frame Number).
Page Fault When the referenced page is not in RAM (present bit = 0), a page fault interrupt occurs. OS loads the missing page from disk (swap space) into a free frame. Can be slow (~1–10 ms).
TLB (Translation Look-aside Buffer) Small, fast CAM cache storing recent VPN→PFN translations. If VPN found in TLB (TLB hit) → fast translation; else (TLB miss) → walk the page table. TLB hit rates typically 99%+.
Segmentation Alternative approach: divides address space into variable-length segments (code, data, stack). Address = Segment Number + Offset. More natural for programs but leads to external fragmentation.
Demand Paging Pages loaded into RAM only when first accessed (not all at program start). Reduces startup time and memory usage. Most modern OSes use demand paging.
Page Replacement When RAM is full and a new page is needed: LRU (evict least-recently used page), FIFO, Optimal (theoretical best — evict page used farthest in future), Clock/Second-Chance (practical LRU approximation).
