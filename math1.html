Set Theory

A set is a well-defined collection of distinct objects called elements or members. Sets are the foundation of all mathematics.

Notation: Sets are written in curly braces. A = {1, 2, 3, 4, 5}

🔢 Finite Set
A = {1, 2, 3} — has countable elements
♾️ Infinite Set
N = {1,2,3,...} — elements go on forever
∅ Empty Set
∅ or {} — set with no elements
🌐 Universal Set
U — contains all elements under discussion
🔗 Subset
A ⊆ B — every element of A is in B
⊂ Proper Subset
A ⊂ B — A ⊆ B but A ≠ B

Set Operations

OperationSymbolMeaningExample (A={1,2,3}, B={2,3,4})
UnionA ∪ BAll elements in A or B or both{1, 2, 3, 4}
IntersectionA ∩ BElements in both A and B{2, 3}
DifferenceA − BElements in A but not in B{1}
ComplementA'Elements in U but not in AU − A
Symmetric DiffA △ B(A−B) ∪ (B−A){1, 4}

De Morgan's Laws (Very Important for Exams!)

De Morgan's Laws (A ∪ B)' = A' ∩ B'   // Complement of union = intersection of complements
(A ∩ B)' = A' ∪ B'   // Complement of intersection = union of complements

Cardinality Formulas

Number of elements formula n(A ∪ B) = n(A) + n(B) − n(A ∩ B)

n(A ∪ B ∪ C) = n(A)+n(B)+n(C) − n(A∩B) − n(B∩C) − n(A∩C) + n(A∩B∩C)
📝 Exam Example

Q: In a class of 60 students, 35 play cricket, 30 play football, and 15 play both. How many play neither?

Sol: n(C ∪ F) = 35 + 30 − 15 = 50

Neither = 60 − 50 = 10 students ✓

Power Set

The power set P(A) is the set of all subsets of A. If A has n elements, P(A) has 2ⁿ elements.

Power Set If A = {1, 2} → n = 2
P(A) = {∅, {1}, {2}, {1,2}}
|P(A)| = 2² = 4
✅ Key Points to Remember Every set is a subset of itself (A ⊆ A) · Empty set is a subset of every set (∅ ⊆ A) · n(∅) = 0 · Sets are unordered — {1,2} = {2,1}

Relations & Functions

A relation from set A to set B is a subset of the Cartesian product A × B. It describes how elements of A are related to elements of B.

Cartesian Product A = {1,2}, B = {a,b}
A × B = {(1,a), (1,b), (2,a), (2,b)}
n(A × B) = n(A) × n(B) = 2 × 2 = 4

Types of Relations

TypeConditionExample
Reflexive(a, a) ∈ R for all a ∈ A"is equal to" — a = a ✓
SymmetricIf (a,b) ∈ R then (b,a) ∈ R"is sibling of" — if A is sibling of B, B is sibling of A
TransitiveIf (a,b) ∈ R and (b,c) ∈ R → (a,c) ∈ R"is less than" — if a<b and b<c then a<c
EquivalenceReflexive + Symmetric + Transitive"is congruent to" in geometry
Anti-symmetricIf (a,b)∈R and (b,a)∈R → a=b"is divisor of" — if a|b and b|a then a=b

Functions

A function f: A → B is a special relation where every element of A maps to exactly one element of B.

TypeConditionExample
One-One (Injective)Different inputs → different outputs; f(a)=f(b) ⟹ a=bf(x) = 2x
Onto (Surjective)Every element of B has at least one pre-imagef: R → R, f(x) = x³
BijectiveBoth one-one AND ontof(x) = x+1 from Z to Z
IntoAt least one element of B has no pre-imagef(x) = x² from R to R (negatives unused)
📌 Composition of Functions If f: A→B and g: B→C, then gof: A→C is defined as (gof)(x) = g(f(x)). Read from right to left — apply f first, then g.
03
Matrices & Determinants

A matrix is a rectangular arrangement of numbers in rows and columns. A matrix with m rows and n columns is called an m × n matrix.

Matrix Notation — 2×3 Matrix A = [aᵢⱼ] where i = row, j = column

| 1 2 3 |
| 4 5 6 |

Order = 2 × 3 (2 rows, 3 columns)

Types of Matrices

Square Matrix
m = n (equal rows & columns). e.g. 2×2, 3×3
Identity Matrix (I)
Diagonal = 1, rest = 0. AI = IA = A
Zero Matrix (O)
All elements are 0. A + O = A
Diagonal Matrix
Non-diagonal elements are 0
Symmetric Matrix
A = Aᵀ (transpose equals original)
Skew-Symmetric
A = −Aᵀ (diagonal elements = 0)

Matrix Operations

Addition & Subtraction (same order only) (A + B)ᵢⱼ = Aᵢⱼ + Bᵢⱼ
(A − B)ᵢⱼ = Aᵢⱼ − Bᵢⱼ

Multiplication — A(m×n) × B(n×p) = C(m×p) Cᵢⱼ = Σ Aᵢₖ × Bₖⱼ  // dot product of row i of A and col j of B

Scalar Multiplication (kA)ᵢⱼ = k × Aᵢⱼ
⚠️ Matrix Multiplication is NOT Commutative! In general, AB ≠ BA. Always check that number of columns in A = number of rows in B before multiplying.

Transpose of a Matrix

Transpose — flip rows and columns If A = [[1,2],[3,4],[5,6]] (3×2)
Aᵀ = [[1,3,5],[2,4,6]] (2×3)

Properties of Transpose (Aᵀ)ᵀ = A
(A+B)ᵀ = Aᵀ + Bᵀ
(AB)ᵀ = BᵀAᵀ  // order reverses!

Determinants

The determinant is a scalar value computed from a square matrix. Denoted det(A) or |A|.

2×2 Determinant |A| = |a b| = ad − bc
      |c d|

Example: |3 2| = 3×4 − 2×1 = 12 − 2 = 10
         |1 4|

3×3 Determinant (Cofactor Expansion along Row 1) |A| = a₁₁(a₂₂a₃₃−a₂₃a₃₂) − a₁₂(a₂₁a₃₃−a₂₃a₃₁) + a₁₃(a₂₁a₃₂−a₂₂a₃₁)

Properties of Determinants

PropertyStatement
Identitydet(I) = 1
Zero row/colIf any row or column is all zeros → det = 0
Identical rowsIf two rows are identical → det = 0
Row interchangeSwapping two rows changes sign of determinant
Scalardet(kA) = kⁿ det(A) where n = order
Productdet(AB) = det(A) × det(B)
Transposedet(Aᵀ) = det(A)

Inverse of a Matrix

Inverse exists only if det(A) ≠ 0 (Non-singular matrix) A⁻¹ = (1/|A|) × adj(A)

For 2×2 matrix A = [[a,b],[c,d]] A⁻¹ = (1/(ad−bc)) × [[d, −b],[−c, a]]

Properties A × A⁻¹ = A⁻¹ × A = I
(AB)⁻¹ = B⁻¹A⁻¹
🔑 Cramer's Rule — Solving Linear Equations For system AX = B:   x = Dₓ/D,   y = Dᵧ/D,   z = D_z/D where D = det(A), Dₓ = det(A with x-column replaced by B), etc.

Progressions (AP & GP)

A progression is a sequence of numbers following a definite pattern. BCA Sem 1 covers two types: Arithmetic Progression (AP) and Geometric Progression (GP).

Arithmetic Progression (AP)

A sequence where each term differs from the previous by a constant value called the common difference (d).

General form: a, a+d, a+2d, a+3d, ...

AP Formulas — Must Memorize! nᵗʰ term: aₙ = a + (n−1)d
Sum of n terms: Sₙ = n/2 [2a + (n−1)d]
Also: Sₙ = n/2 [a + l]  // l = last term
Common difference: d = aₙ − aₙ₋₁
📝 Solved Example

Q: Find the 15th term and sum of 20 terms of AP: 3, 7, 11, 15, ...

a = 3, d = 7−3 = 4

a₁₅ = 3 + (15−1)×4 = 3 + 56 = 59

S₂₀ = 20/2 [2×3 + (20−1)×4] = 10[6 + 76] = 10 × 82 = 820

Geometric Progression (GP)

A sequence where each term is obtained by multiplying the previous term by a constant value called the common ratio (r).

General form: a, ar, ar², ar³, ...

GP Formulas — Must Memorize! nᵗʰ term: aₙ = arⁿ⁻¹
Sum (r ≠ 1): Sₙ = a(rⁿ − 1)/(r − 1)  if r > 1
Sum (r ≠ 1): Sₙ = a(1 − rⁿ)/(1 − r)  if r < 1
Sum of ∞ GP (|r| < 1): S∞ = a/(1−r)
Common ratio: r = aₙ/aₙ₋₁
📝 Solved Example

Q: Find the 6th term and sum of 5 terms of GP: 2, 6, 18, 54, ...

a = 2, r = 6/2 = 3

a₆ = 2 × 3⁵ = 2 × 243 = 486

S₅ = 2(3⁵ − 1)/(3 − 1) = 2(243−1)/2 = 242

PropertyAPGP
PatternAdd constant dMultiply constant r
nth terma + (n−1)darⁿ⁻¹
Sum formulan/2[2a+(n−1)d]a(rⁿ−1)/(r−1)
Arithmetic MeanAM = (a+b)/2GM = √(ab)
RelationAM ≥ GM (always, for positive numbers)
✅ AM-GM Inequality For any two positive numbers a and b: (a+b)/2 ≥ √(ab). Equality holds only when a = b.

Trigonometry

Trigonometry deals with the relationships between the sides and angles of triangles. In a right triangle with angle θ:

Basic Ratios — SOH-CAH-TOA sin θ = Opposite / Hypotenuse
cos θ = Adjacent / Hypotenuse
tan θ = Opposite / Adjacent = sin θ / cos θ

cosec θ = 1/sin θ
sec θ = 1/cos θ
cot θ = 1/tan θ = cos θ / sin θ

Fundamental Identities

Pythagorean Identities sin²θ + cos²θ = 1
1 + tan²θ = sec²θ

Compound Angle Formulas sin(A+B) = sinA cosB + cosA sinB
sin(A−B) = sinA cosB − cosA sinB
cos(A+B) = cosA cosB − sinA sinB
cos(A−B) = cosA cosB + sinA sinB
tan(A+B) = (tanA + tanB)/(1 − tanA tanB)

Quadrants: I (All), II (Sin), III (Tan), IV (Cos)

Limits & Continuity

The limit of a function f(x) as x approaches a value 'a' is the value that f(x) gets closer and closer to. Written as: lim(x→a) f(x) = L

Standard Limits — Exam Favourites lim(x→0) sin x / x = 1
lim(x→0) tan x / x = 1
lim(x→0) (eˣ − 1) / x = 1
lim(x→0) (aˣ − 1) / x = log a
lim(x→∞) (1 + 1/x)ˣ = e
lim(x→a) (xⁿ − aⁿ)/(x − a) = n · aⁿ⁻¹

Methods to Evaluate Limits

1
Direct Substitution: Simply put x = a. If you get a definite value, that's your limit.
2
Factorisation: If you get 0/0 form, factor numerator and denominator, cancel common factor, then substitute.
3
Rationalisation: Multiply numerator and denominator by conjugate (used with square roots).
4
L'Hôpital's Rule: If 0/0 or ∞/∞ form → differentiate numerator and denominator separately, then substitute.
📝 Solved Example

Q: Find lim(x→2) (x² − 4)/(x − 2)

Direct substitution gives 0/0 form (indeterminate)

Factorise: (x²−4) = (x+2)(x−2)

= lim(x→2) (x+2)(x−2)/(x−2) = lim(x→2) (x+2) = 2+2 = 4

Continuity

A function f(x) is continuous at x = a if all three conditions hold:

Three Conditions for Continuity at x = a 1. f(a) is defined
2. lim(x→a) f(x) exists
3. lim(x→a) f(x) = f(a)

Also: Left Hand Limit = Right Hand Limit = f(a)
⚠️ Common Discontinuities Removable discontinuity (hole), Jump discontinuity (step function), Infinite discontinuity (vertical asymptote like 1/x at x=0)

Differentiation

Differentiation is the process of finding the derivative of a function — the rate at which the function changes. The derivative of f(x) is written as f'(x) or dy/dx.

Definition from First Principles f'(x) = lim(h→0) [f(x+h) − f(x)] / h

Rules of Differentiation

Sum/Difference Rule d/dx [f(x) ± g(x)] = f'(x) ± g'(x)

Product Rule (UV Rule) d/dx [u·v] = u·v' + v·u'

Quotient Rule (U/V Rule) d/dx [u/v] = (v·u' − u·v') / v²

Chain Rule — Composite Functions d/dx [f(g(x))] = f'(g(x)) · g'(x)
Example: d/dx[sin(x²)] = cos(x²) · 2x

dy/dx = 3x² + 10x − 3

Integration

Integration is the reverse process of differentiation. It is also used to find the area under a curve. The integral of f(x) is written as ∫f(x)dx.

Two types of Integration Indefinite: ∫f(x)dx = F(x) + C  // C = constant of integration
Definite: ∫[a to b] f(x)dx = F(b) − F(a)

Methods of Integration

Method 1: Substitution (u-substitution) Put t = g(x), then dt = g'(x)dx, substitute and integrate
Example: ∫2x·sin(x²)dx → let t = x², dt = 2x dx
= ∫sin(t)dt = −cos(t) + C = −cos(x²) + C

Method 2: Integration by Parts (ILATE Rule) ∫u·v dx = u·∫v dx − ∫(du/dx · ∫v dx) dx
ILATE: Inverse trig, Logarithm, Algebra, Trig, Exponential
(Choose u as the function that comes first in ILATE)

Method 3: Partial Fractions Used when integrand is a rational function (fraction of polynomials)
Example: ∫1/(x²−1)dx = ∫[A/(x−1) + B/(x+1)]dx
📝 Solved Example

Q: Evaluate ∫(3x² + 2x − 5)dx

= 3·(x³/3) + 2·(x²/2) − 5x + C

= x³ + x² − 5x + C

Q: Evaluate ∫₀² (x² + 1)dx

= [x³/3 + x]₀²

= (8/3 + 2) − (0 + 0) = 8/3 + 2 = 14/3

✅ Fundamental Theorem of Calculus Differentiation and Integration are inverse operations: d/dx[∫f(x)dx] = f(x). This is why integration is also called "anti-differentiation."
📐 Application — Area Under Curve Area bounded by y = f(x), x-axis, x = a and x = b is: A = ∫[a to b] |f(x)| dx (Take modulus because area is always positive)
