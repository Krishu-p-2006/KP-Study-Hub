01

Arrays

An array is a collection of elements of the same data type stored in contiguous memory locations. Think of it as a row of numbered boxes — each box holds one value, and every box is the same size.

Key Idea: Arrays give you O(1) random access — you can jump to any element instantly using its index, because the memory address is calculated as:
address = base_address + (index × size_of_element)
Declaration & Initialization
CArray Declaration
// Syntax: data_type  array_name[size];

int  marks[5];                          // uninitialized
int  primes[5] = {2, 3, 5, 7, 11};     // initialized
int  zeros[10] = {0};                    // all elements = 0
char grade[3] = {'A', 'B', 'C'};        // char array
float temp[] = {36.5, 37.0, 38.2};      // size auto-inferred = 3

// Accessing elements (0-indexed)
primes[0] = 2;   // first element
primes[4] = 11;  // last element (index = size-1)
📊 1D Array — Memory Layout
2D Arrays

A 2D array is an array of arrays — like a table with rows and columns. In memory it is still stored as one continuous block, row by row (row-major order).

C2D Array
int matrix[3][4];              // 3 rows, 4 columns

int grid[2][3] = {
  {1, 2, 3},                   // row 0
  {4, 5, 6}                    // row 1
};

// Access: grid[row][col]
int val = grid[1][2];           // = 6

// Traverse with nested loops
for(int i=0; i<2; i++)
  for(int j=0; j<3; j++)
    printf("%d ", grid[i][j]);
📊 2D Array — Row-Major Memory Layout
Common Array Operations
CTraversal, Search, Sum
int arr[] = {10, 20, 30, 40, 50};
int n = sizeof(arr) / sizeof(arr[0]);  // n = 5

// Sum of all elements
int sum = 0;
for(int i=0; i<n; i++) sum += arr[i];

// Linear search
int target = 30, found = -1;
for(int i=0; i<n; i++)
  if(arr[i] == target) { found = i; break; }

// Reverse an array
int left=0, right=n-1;
while(left < right){
  int tmp = arr[left];
  arr[left++] = arr[right];
  arr[right--] = tmp;
}
⚠️ Common Mistake: Array index goes from 0 to n-1. Accessing arr[n] is out of bounds — it causes undefined behavior or crashes!
02

Strings

In C, a string is simply an array of char terminated by a special null character '\0' (ASCII 0). There is no built-in string type — strings are always character arrays.

Remember: A string of n characters needs an array of size n+1 to hold the null terminator '\0'.
CString Declaration
// Method 1: char array with literal
char name[6] = {'H','e','l','l','o','\0'};

// Method 2: string literal (compiler adds '\0' automatically)
char name[] = "Hello";        // size = 6 (5 chars + null)

// Method 3: pointer to string (read-only, stored in data segment)
char *msg = "Hello World";   // cannot modify msg[i]

// Reading a string from user
char input[50];
scanf("%s", input);          // stops at whitespace
fgets(input, 50, stdin);     // reads full line (safer)

03

Pointers

A pointer is a variable that stores the memory address of another variable. Instead of holding a value like 42, it holds an address like 0x1004. Pointers are one of C's most powerful — and most misunderstood — features.

📍
& Operator
Address-of operator. Gets the memory address of a variable.
&x → address of x
🔍
* Operator
Dereference operator. Gets the value at a pointer's address.
*p → value at address p
🔢
Pointer Arithmetic
p+1 moves by sizeof(type) bytes, not just 1 byte.
⛔
NULL Pointer
A pointer that points nowhere. Always initialise pointers to NULL if not used immediately.
CPointer Basics
int  x = 42;
int *p;           // declare a pointer to int
p = &x;           // p now holds address of x

printf("%d",  x);   // 42       — value of x
printf("%p", &x);   // 0x1004   — address of x
printf("%p",  p);   // 0x1004   — value stored in p
printf("%d", *p);   // 42       — value AT address p

*p = 100;           // changes x through pointer!
printf("%d", x);    // 100
👉 Pointer — Address & Dereference
Pointer Arithmetic
CPointer Arithmetic
int arr[] = {10, 20, 30, 40};
int *p = arr;       // p points to arr[0]

printf("%d", *p);        // 10  (arr[0])
printf("%d", *(p+1));    // 20  (arr[1])
printf("%d", *(p+2));    // 30  (arr[2])

p++;                     // moves forward by sizeof(int)=4 bytes
printf("%d", *p);        // 20  (now at arr[1])

// Traverse array using pointer
for(int *q = arr; q < arr+4; q++)
  printf("%d ", *q);   // 10 20 30 40
Pointers & Functions
CPass by Pointer (call by reference)
// Without pointer: changes don't affect original
void addOne(int x){ x++; }     // x is a copy

// With pointer: changes DO affect original
void addOneP(int *x){ (*x)++; }

int main(){
  int n = 5;
  addOne(n);   // n is still 5
  addOneP(&n); // n is now 6  ✓

  // Swap using pointers
  int a=3, b=7;
  int tmp=a; a=b; b=tmp;         // classic swap
}
⚠️ Dangling Pointer: Never use a pointer after the variable it points to has been freed or gone out of scope. Always set pointers to NULL after freeing: free(p); p = NULL;
04

Structures

A structure (struct) is a user-defined data type that groups together variables of different types under a single name. Each variable inside a structure is called a member or field.

Structures are the foundation of object-oriented thinking in C — a struct Student can hold name, roll number, and marks together, just like a real student record.

CStructure Definition & Usage
// Define the structure (no memory allocated yet)
struct Student {
  int  roll;
  char name[50];
  float marks;
};

int main(){
  // Declare and initialize
  struct Student s1 = {101, "Alice", 95.5};
  struct Student s2;

  // Access members with dot operator
  s2.roll  = 102;
  strcpy(s2.name, "Bob");
  s2.marks = 88.0;

  printf("%d %s %.1f\n", s1.roll, s1.name, s1.marks);

  // typedef makes syntax cleaner
  typedef struct { int x; int y; } Point;
  Point p = {3, 4};    // no 'struct' keyword needed
}
🏗️ Struct Memory Layout — struct Student
Pointer to Structure
CStruct Pointer & Arrow Operator
struct Student s1 = {101, "Alice", 95.5};
struct Student *ptr = &s1;

// Two ways to access through pointer:
(*ptr).roll          // dereference then dot  (verbose)
ptr->roll            // arrow operator        (preferred) ✓

printf("%s", ptr->name);    // Alice
ptr->marks = 99.0;         // modify through pointer

// Array of structures
struct Student class[30];
class[0].roll = 1;
class[0].marks = 78.5;
💡 Nested Structures: A struct can contain another struct as a member. Example: a struct Address can be a member of struct Student, letting you write s1.addr.city.

Unions

A union is like a structure — it can hold multiple members of different types. The critical difference is that all members in a union share the same memory location. Only one member can hold a valid value at a time.

The size of a union equals the size of its largest member. This makes unions extremely memory-efficient when you only ever need one field at a time.

🔀 Union vs Struct — Memory Comparison
CUnion Example
union Data {
  int   i;
  float f;
  char  c;
};

int main(){
  union Data d;

  d.i = 42;
  printf("%d\n", d.i);     // 42  ✓ valid
  printf("%f\n", d.f);     // garbage! (same bytes, different interpretation)

  d.f = 3.14;
  printf("%f\n", d.f);     // 3.14 ✓ valid now
  printf("%d\n", d.i);     // garbage now!

  printf("%lu\n", sizeof(d));  // 4 bytes (size of largest member)
}

File Handling

File handling in C allows programs to persist data beyond program execution. Data written to a file survives after the program closes. C uses a file pointer (FILE *) and functions from <stdio.h> to interact with files.

📁 File Handling — Complete Flow
File Opening Modes

"rb"Read binaryOpens in binary modeReturns NULL

Core File Functions
CWriting to a File
#include <stdio.h>

int main(){
  FILE *fp = fopen("data.txt", "w");

  if(fp == NULL){
    printf("Error: cannot open file!\n");
    return 1;
  }

  fprintf(fp, "Hello File!\n");         // formatted write
  fputs("Second line\n", fp);         // string write
  fputc('A', fp);                      // single char write

  fclose(fp);                           // ALWAYS close!
  return 0;
}
CReading from a File
FILE *fp = fopen("data.txt", "r");
if(!fp){ perror("fopen"); return 1; }

char buf[100];

// Read line by line
while(fgets(buf, sizeof(buf), fp) != NULL)
  printf("%s", buf);

fclose(fp);

// Or character by character
fp = fopen("data.txt", "r");
int ch;
while((ch = fgetc(fp)) != EOF)
  putchar(ch);
fclose(fp);
CBinary File — fread & fwrite
struct Student s = {1, "Alice", 95.5};
FILE *fp;

// Write struct to binary file
fp = fopen("students.bin", "wb");
fwrite(&s, sizeof(s), 1, fp);     // write 1 struct
fclose(fp);

// Read struct back from binary file
struct Student s2;
fp = fopen("students.bin", "rb");
fread(&s2, sizeof(s2), 1, fp);   // read 1 struct
fclose(fp);
printf("%s %.1f\n", s2.name, s2.marks);
📋 File Functions Quick Reference
⚠️ Never forget to fclose()! If you skip fclose(), data may still be in the buffer and never actually written to disk. Closing the file flushes all pending writes and releases the OS file handle.
💡 Error Checking Pattern: Always check if fopen() returned NULL. Use perror("fopen") to print a descriptive OS error message automatically.
